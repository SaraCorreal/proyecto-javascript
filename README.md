# Proyecto JavaScript

Aplicación básica con Node.js y Express que sirve una página HTML estática.

## Requisitos

- Node.js 18 o superior
- npm

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm start
```

Luego abre el navegador en:

```text
http://localhost:3000
```

## Script de desarrollo

```bash
npm run dev
```

Este comando usa `nodemon` para reiniciar el servidor automáticamente durante el desarrollo.
